# QQ 动态发布向导设计

## 目标

单独发送 `/动态` 时进入逐步问答，降低手机聊天窗口中的输入成本；带参数的
`/动态 内容 #标签` 和微信/QQ 私聊普通文字直接开稿继续保留。

## 流程

1. 标题：可选，回复“跳过”表示无标题。
2. 正文：必填，不允许跳过。
3. 心情：提供常用编号，也接受自由输入；回复“跳过”使用 `moment_tags[0]`。
4. 普通标签：可输入空格、逗号或 `#` 分隔的多个标签；可跳过。
5. 图片：可连续发送多张；回复“完成”进入下一步，回复“跳过”表示无图片。
6. 发布时间：接受现有时间解析格式；跳过时取当下时间。
7. 确认：展示标题、正文、心情、普通标签、图片数和时间；只有回复“发布”才提交。

## 控制指令

- `取消`：删除整个会话。
- `预览`：随时查看当前已填写内容。
- `上一步`：返回上一个步骤，保留已填写数据。
- 确认页支持“修改标题 / 修改内容 / 修改心情 / 修改标签 / 修改图片 / 修改时间”。
- 图片步骤支持“清空图片”。

## 数据规则

- `tags[0]` 必须是心情标签。
- 普通标签从 `tags[1:]` 开始，去掉 `#`、空白和重复项，也不重复心情。
- 未输入标题时不生成 `title` frontmatter。
- 向导完成前收到“发布”必须拒绝，并提示继续当前步骤。

## 验证

- 完整无图流程能发布，默认时间为确认前的当前时间。
- 编号心情和自由输入心情都能写入 `tags[0]`。
- 多张图片可连续收集，“完成”后才进入时间步骤。
- 旧快捷命令与普通私聊草稿测试保持通过。
