# 手机端站长入口与内容编辑方案

日期：2026-11-07

## 目标

在不增加明显常驻管理控件的前提下，让站长可以在手机上完成登录、发布或修改说说，以及进入作品管理页面。

## 已确认方向

采用“导航菜单末项 + 登录后上下文编辑”：

- 未登录时，页面和资料卡不显示任何登录入口。
- “站长登录”放在手机底部 Dock 打开的菜单弹窗最底部，与普通导航分区，并使用低对比度辅助文字样式。
- 登录后，说说卡片右上角出现低对比度三点按钮，点击后才展示编辑与删除操作。
- 登录后，导航菜单末项切换为“内容管理”和“退出登录”。
- 不增加全站悬浮按钮，不增加手机端常驻管理底栏。

## 手机说说编辑器

- 使用接近全屏的编辑页，顶部提供返回、标题和提交操作。
- 正文与图片入口优先展示。
- 标题、心情、标签、地点、发布时间和置顶状态放入“更多设置”折叠区。
- 底部提示“提交后约 1 至 3 分钟生效”，避免把提交描述为立即发布。
- 删除操作放入更多菜单并要求二次确认。

## 手机作品管理

- 第一层为内容类型横向切换和作品列表。
- 点击作品后进入单页编辑状态，使用原生返回路径回到列表。
- 列表只读取文件名和基础目录信息，不增加批量 frontmatter 请求。
- 文章编辑保留现有字段配置、Markdown 正文和预览能力。

## 交互与可访问性

- 可见按钮可以低调，但触控区域不得小于 44 × 44 CSS 像素。
- 相邻触控区域至少保留 8 像素间距。
- 所有图标按钮需要可读的 `aria-label`。
- 固定顶部和底部操作栏需要适配 `safe-area-inset-*`。
- 支持 `prefers-reduced-motion`，不依赖悬停才能完成操作。

## 原型范围

`docs/prototypes/mobile-editor-concept.html` 是独立 HTML 交互方案图，只用于确认布局与流程，不连接 GitHub OAuth、Cloudflare Worker 或真实内容接口。
