## 友链申请区块（/friends/）

下方评论区（Waline）保持原样不动，在其上方新增独立区块 `FriendApply.astro`：

- **右侧四个输入卡**（照参考站样式，RSS 已按要求去掉）：站点名称 / 站点描述 / 站点链接 /
  头像链接，每项带 T / D / 链接 / IMG 徽标与单字段复制按钮
- **左侧实时预览**：输入即变 —— 圆形头像（加载失败自动回退占位）、站点名（主色）、
  描述两侧小圆点装饰，空值显示灰色占位文字
- **复制申请信息**：四项**必须一起填**（可单独只发普通留言，不经过本区块），
  缺项时红字提示"还差：×××"并聚焦第一个缺失输入框；齐全后复制成
  `站点名称: …\n站点描述: …\n站点链接: …\n头像链接: …` 四行文本，
  粘贴到下方评论区发送即可
- 「添加友链」按钮的滚动目标从评论区改为本区块（无区块时退回评论区）
- 复制兼容降级：clipboard API 被拒（如 http 环境）时自动回退 execCommand，无 unhandled rejection
- 脚本为 document 级事件委托 + window 守卫，Swup 换页不重复绑定；
  全部元素静态渲染（无动态建节点），Astro scoped 样式直接命中

### 期间踩到的两个 Waline 坑（自动发送已下线，但留档）

1. **编辑器 `visibility:hidden` / `opacity:0` → Waline 直接拒绝提交**（实测 0 次请求）。
   想让填充"看不见"只能用 `color: transparent`（不改可见性），否则提交静默失效
2. **编辑器状态是异步更新的**：写完 `textarea.value` 并派发 input 后**立刻**点提交，
   Waline 读到的还是上一帧内容 → 同样 0 次请求。必须 `setTimeout(…, 300)` 再点
