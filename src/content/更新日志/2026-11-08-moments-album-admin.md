## 说说、相册都长出了「管理」入口

登录之后，说说页封面右上角和相册页工具栏上会多一个「管理」按钮。以前改一条说说得开 GitHub 改 md 文件、传图得先本地压好再 push，现在这套动作全在页面里完成。

### 说说页

- **管理菜单**：`新增说说` / `编辑说说` / `批量删除`。
- **多选删除**：进入多选态后卡片左上角出现勾选圈，底部浮起工具条（已选 N 条 / 全选 / 删除 / 取消），删除走两段确认，避免手滑。
- **新建说说弹窗重排**：字段顺序改成 `① 标题 → ② 正文 → ③ 图片 → 心情 → 话题 → 时间地点`，前三项带编号，一眼看得出填写顺序。
- **图片三种进法**：拖进虚线框、点一下开文件选择器（可多选）、贴图片 URL 回车。缩略图是九宫格，第一张自动作封面并带「封面」角标，可拖动排序、可单张删除，上传中盖一层转圈。
- **心情和话题分开**：文件里它俩同属 `tags`（第一项是心情），但界面拆成两个控件 —— 心情是 8 个带色 chip（沿用 `moment-mood.ts` 的配色），话题是自由输入的标签。保存时再拼回去，所有既有渲染逻辑和筛选都不用动。
- 图片在文件里依然是正文末尾的 `![](assets/diary/xxx.webp)`，只是界面不再要求你手写这行语法。

### 相册页

- **新增照片**：一次可挑多张，同样支持拖拽 / 选文件 / 贴 URL；写入目标优先跟 `localFolder`，保证和目录扫描结果按 `src` 去重后表现为同一批照片。
- **编辑描述**：多选态下选中一张点「编辑」，改描述、标签、拍摄时间、alt。
- **删除照片**：可多选，一次读取 → 过滤 → 写回，同一本相册只产生一次 commit。
- **边界**：相册照片有两份来源 —— json 里声明的 `photos` 和 `localFolder` 目录扫描出来的文件。后者不在 json 里，删不掉，遇到时会明确提示「需要在仓库里删文件」，而不是假装成功。

### 底层

- **新增 Worker 路由 `PUT /api/github/blob`**：`/api/github/file` 走 `textToBase64`（UTF-8 重编码），图片进去必然损坏；新路由只收 base64 原串直接 PUT，上限 8MB。**Worker 需要重新部署，图片上传才会在线上生效。**
- `src/utils/editor/image-upload.ts`：上传前用 canvas 缩到长边 1920 再转 webp（质量 0.86），gif/svg 原样直传，手机直出的大图不会把仓库撑爆。
- `src/utils/editor/album-serializer.ts` + 8 条单测：相册文件是 json，读写走 `JSON.parse/stringify`，**不认识的键原样保留**（`cover`、`imgbedFolder`、`draft` 以及逐张照片的未知字段）。单测里抓到一个真 bug：`draft` 一开始被列进已知键却没读进草稿，保存一次就会把草稿相册「偷偷发布」。
- `src/utils/moment-media.ts` 增加 `splitMomentMedia()`：载入时把图片语法从正文里拆出来，保存时按列表顺序拼回。
- 相册页的管理交互是内联脚本 + 事件委托（`album:open-photo` 自定义事件交给常驻的 Svelte 弹窗），跟说说页同构 —— Swup 换页会把静态 DOM 整个换掉，挂在元素上的监听活不过一次导航。
