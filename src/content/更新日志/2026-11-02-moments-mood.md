## 图片：从固定小方块到朋友圈九宫格

原来三个列宽是写死的 `100px / 90px / 90px`，一条说说里的图永远是那几颗小方块，卡片再宽也不长。现在改成固定三列等宽（`repeat(3, minmax(0, 1fr))`，间距 4px，圆角 4px），按数量切布局：

- 1 张：单张大图，4:3，最宽 260
- 2 张 / 4 张：两列，最宽 324
- 3 张及以上：三列，最宽 486（每格约 160）
- 超过 9 张：只排前 9 格，第 9 格压暗并盖 `+N`，点开灯箱仍是全图

最后一行不满就靠左，不拉伸不居中。手机上（≤480px）取消上限，直接铺满卡片宽度。

## 心情：emoji + 两个字，八套配色

心情一直是 `tags` 的第一项，之前只会渲染成卡片底部的黑色描边胶囊。现在单独提到**卡片右上角**，与作者名同一行右对齐，形态统一成「emoji + 两个字」：

| 心情 | 别名（自动归位） | 色系 |
| --- | --- | --- |
| 😄 开心 | 快乐 / 高兴 / 爽 / 嗨 | 琥珀 |
| 😌 平淡 | 平平淡淡 / 日常 / 佛系 | 中性灰 |
| 😢 难过 | 伤心 / 伤心难过 / 不开心 / emo | 蓝 |
| 😤 生气 | 愤怒 / 不爽 / 破防 | 红 |
| 😩 疲惫 | 累 / 心累 / 困 / 熬夜 | 紫 |
| 🤩 兴奋 | 激动 / 期待 / 上头 | 粉 |
| 🤔 好奇 | 涨知识 / 学到了 / 疑问 | 青 |
| 😶 无语 | 绷不住 / 尴尬 / 吐槽 | 沙 |

词表在 `src/utils/moment-mood.ts`，八套「底 / 字 / 边」颜色令牌在 `src/styles/tokens/colors.css`（浅深各一份）。老文章一个字都不用改：「平平淡淡」自动变成「😌 平淡」。**只有命中词表的标签才算心情**，像「额的圣剑！」「功能」这种继续留在卡片底部当话题标签。

## 一处必须同时改的旧样式

`src/styles/features/moments.css` 里有一套 `#moments-feed .image-cols-1 { grid-template-columns: 100px }`。它带 ID 选择器，特异性高过组件 scoped 样式——只改 `MomentCard.astro` 的话，网格尺寸会被它按回 100px（第一次构建出来就是这个坑，量了一下 cell 还是 100×100）。所以两边现在保持同一套规则，文件里也写了注释提醒同步。

顺手去掉这条链路上的 `display: none !important`，改成普通声明。
