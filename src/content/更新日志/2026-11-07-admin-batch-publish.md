## 后台支持批量提交内容

- 新建文章、说说或更新日志时，可以先加入待提交队列，再继续编辑下一条内容。
- 同一批队列允许混合不同内容类型，支持重新编辑、移除、清空和刷新页面后恢复。
- 点击“提交全部”后，所有 Markdown 文件只生成一个 Git 提交，只触发一次网站构建。
- 同一天多条说说或同名文章会自动追加 `-2`、`-3`，避免覆盖已有内容。
- 批量提交失败时完整保留队列，不会出现只提交一半的状态。

## 使用说明

1. 进入 `/admin`，选择任意内容类型并点击“新建”。
2. 编辑完成后点击“加入待提交”，继续创建下一条内容。
3. 点击顶栏“待提交”查看整批内容，确认后选择“提交全部”。
