## 影视与游戏页（/movies-games/）改版

站长给的参考图是「左栏筛选 + 右侧卡片网格」的媒体库布局，于是把原来「页面上方一排 tab + 一排状态筛选 + 分页」的结构整个换掉：

- **左栏**（sticky，参考动态页那一列）：**搜索 → 观看日期 → 排序 → 类型 → 观看状态 → 标签**（顺序为站长指定，日历就在搜索下面）。
  - **排序**：日期 ↓ / 日期 ↑ / 评分 ↓ / 评分 ↑ 四个按钮（按 DOM 顺序重排卡片）。
  - **类型**：全部 / 电影 / 电视剧 / 番剧 / 纪录片 / 游戏 + 条数 —— 就是原来页面上方那排 tab 的判定（游戏看 `subject_type`，其余看 `subcategory`）。
  - **观看状态**：全部 / 看过 / 在看 / 想看 / 搁置 / 抛弃 + 条数 —— 原来页面上方那排筛选。
  - **标签**：条目 `tags` 的并集（现在有数据：剧情 25、动漫 12、喜剧 10…），点谁按谁筛。
  - **观看日期**：月历，有内容的日期带小点，点日期筛那天、点月份标题筛整月（数据取条目的 `published`）。
  - 排序 / 类型 / 观看状态三块**默认收起**（点标题展开），观看日期与标签默认展开。
- **移动端（≤768px）**：左栏整体收进右下角按钮（6 个），**与动态页 /moments/ 完全同一套行为** —— 浮岛在时不显示、浮岛收起（右下角冒出 FloatingDock）时与它同列出现，点谁弹谁，再点/点外部/Esc 收起。
- **右栏**：筛选状态条（每个条件一颗可单独移除的 chip + 条数 + 清空）+ 卡片网格（自适应列数，1440 下 5 列）+ 无结果空态。
- **卡片 UI 不动，只把直角改成圆角**（`border-radius: 0.75rem`）。⚠️ 只改 `.mg-card`，**没动全局 `--radius-large`**（它是 0，全站其它卡片靠它保持直角）。
- **页面左右的小组件全部去掉**：`movies-games` 加进 `NO_SIDEBAR_PAGE_TYPES`；整页宽度取**视口 4/5**（≥1280px `80vw`，与导航站/友链页同一套写法）。
- **左栏尺寸**（站长反馈「太窄太细」后调整）：列宽 13rem → **15.5rem**，块内边距 0.75 → 0.875rem，搜索框/选项/排序按钮的内边距一并放宽。
- **本页手机档也藏掉 FloatingDock 的「展开」**（与动态页同一套）：右下角那排筛选按钮就排在这一列上方，展开会叠在一起。只在本页、只在 ≤768px 生效，「回顶部」保留，桌面档不动。
- **原来的分页（ClientPagination）去掉**：筛选与排序都在前端做，78 条一次性渲染。

### 踩到的坑：类名撞车

新左栏的标签块最初也叫 `.mg-tags` / `.mg-tag`，和**卡片封面上的标签胶囊同名** → 后写的规则把卡片胶囊覆盖成「透明底 + 深色字」，压在封面图上等于没字（站长截图报「标签显示有问题」）。已把左栏那组规则全部限定到 `.mg-side` 前缀下（4 条），卡片胶囊恢复原样（白字 85% + 白底 15% + 毛玻璃）。**以后给这个页面加组件时，先搜一下类名有没有被卡片用掉**。

> 验证：`pnpm check` 0 错误。浏览器实测 1440：左栏 6 块顺序为 `搜索 → 观看日期 → 排序 → 类型 → 观看状态 → 标签`、排序/类型/观看状态 `open=false`、卡片胶囊 `rgba(255,255,255,.85)`/`rgba(255,255,255,.15)`、卡片圆角 12px、网格 5 列、共 78 条；点「电影」→ 状态条「筛选 电影 × 51 条 清空」且可见 51 条。390：左栏 `position: fixed` + `display: none`（面板待命）、右下角 6 个按钮且浮岛在时不显示（与动态页一致）。
