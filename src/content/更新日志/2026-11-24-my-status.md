## 后台新增「我的状态」

进入 `/admin` 左侧多了一项「状态」。每天拍一组照片传上来，一年后往回翻就是一条
能看出变化的时间线。

它和站内其它内容有个根本区别：**数据不在博客仓库里**。

### 为什么另起一个私有仓库

身体状态这类照片不适合放在公开仓库里 —— 即使站点不渲染它们，别人翻仓库也能看到。
所以照片和记录都落在独立的私有仓库（默认 `flowersoul999/afterglow-private`），
由 Cloudflare Worker 新增的 `/api/private/*` 通道代理读写，用一枚只授权这一个仓库的
fine-grained PAT（`PRIVATE_TOKEN`）访问。博客主仓 `src/content/` 里一个字节都不多。

顺带的好处是**保存完立刻生效**：不触发 GitHub Actions，不用等那 1~3 分钟构建。

### 怎么用

- 顶部「记录今天」直接传今天的照片；某一天的卡片上也能「加照片」或把图拖进去。
- 一天一组，多角度就多选几张。原始图长边压到 1600，另存一张 480 的缩略图给时间轴用。
- 点缩略图看大图；hover 右上角的小叉删单张；卡片右侧垃圾桶删整天（会二次确认）。
- 「两日对比」挑两个日期并排看，左右两栏各自可以换日期。

### 数据长什么样

`status/<日期>.json`，薄到只有两个键：

```json
{
	"date": "2026-11-24",
	"photos": ["assets/2026-11/1763999999999-a1b2c3.webp"]
}
```

`photos` 存的是相对 `status/` 的路径，换仓库、换域名都不用改。认不出的键会原样
保留 —— 以后想加体重或备注，不会因为编辑器还没做输入框就被吃掉。

### 底层

- `cloudflare-worker/index.js` 新增 6 条路由：`/api/private/{tree,file,blob,raw}`，
  路径护栏卡死在 `status/` 下，鉴权是「登录态 + 站长身份 + PAT」三关；
  `/raw` 直接把图片字节回给 `<img>`，同源 Cookie 自动带上，并给了 `immutable` 长缓存。
- `src/utils/editor/private-client.ts`、`status-serializer.ts` 是两个新模块；
  `image-upload.ts` 加了 `uploadStatusPhoto`（一次传原图 + 缩略图两张）。
- `src/components/admin/AdminStatusBoard.svelte` 是整块面板，横跨后台中栏和右栏。
  照片按天懒加载 —— 卡片滚进视口才读那一天的 json，不会一进页面就发几十个请求。
- `.workbuddy/preview/test-worker.mjs` 从 25 条断言加到 33 条，覆盖私有通道的三道门
  和 `statusx` 这种前缀撞脸的路径。
