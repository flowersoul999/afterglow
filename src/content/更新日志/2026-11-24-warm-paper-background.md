## 除了首页，其它页面终于有颜色了

站长的原话是「看我的博客除了主页，其他地方的背景全是白色或黑色主题，
能不能加下别的背景颜色，暖色调或者毛玻璃之类的」。

所以这次只动**亮色主题**：原来的纯白 `--page-bg` 变成暖纸米白，
再在 body 最底层铺三团极淡的柔光。暗色保持纯黑，一个字没改（站长明确要求）。

### 暖纸：整条灰阶往黄橙方向偏了一点点

不是单纯把底色调黄就完事 —— 纯中性灰压在米色底上会读作「冷灰」，
同时对比效应会让文字和卡片显脏。所以 `tokens/colors.css` 亮色块里
**整条灰阶一起挪**：

- 底色 `oklch(1 0 0)` → `oklch(0.979 0.011 82)`
- 正文 `--deep-text` 从近纯黑 `0.10` 提到 `0.145`，并带上色相 65 的深褐 ——
  纯黑压米黄太硬，深褐黑才像墨
- 分隔线、边框、代码块底、悬停底、导航胶囊、目录按钮，色度统一控在 `0.010~0.016`，
  色相锁在 `65~82`

色度刻意不超过 0.02：再往上就从「温度」变成「脏黄」了。

### 柔光：三团光，圆心全在视口外面

新文件 `styles/base/ambient-backdrop.css`（已经在 `main.css` 里 import），
用 `body::before` 画三层 `radial-gradient`：

| 光 | 位置 | 作用 |
|---|---|---|
| 暖杏 | 左上（圆心 −4% −12%） | 最主要的那一层，页面「有阳光」的感觉来自它 |
| 薄荷 | 右上（圆心 100% −8%） | 压住顶部，避免整页只有一种黄 |
| 藕紫 | 右下（圆心 104% 106%） | 长页面滚到底时收个尾 |

几个关键处理：

- **圆心全部在视口外**，只让边缘渗进来 —— 否则就是一坨突兀的彩色圆斑，很廉价。
- `position: fixed` + `z-index: -1`：贴在 html 画布之上、所有内容之下，滚动时不动，
  长页面末尾不会断成一截一截。
- `pointer-events: none`，纯装饰，不占布局不挡交互；body 不随 Swup 重建，所以这层
  整个会话都稳定，换页不会闪。
- **首页不生成**（`body[class~="lg:is-home"]`）：首页自带整屏主视觉，不需要再垫一层。
- **暗色不生成**（`:root.dark` 下 `content: none`）。

### 顺手把两处「冷白」换成暖白

页面一变暖，原来那些没色相的白块就显出来了：

1. `components/common/WidgetLayout.astro` 的侧栏卡片，原来是硬编码 `background: #fff`，
   现在是 `var(--float-panel-bg)`（亮色暖白、暗色仍是原值），描边也从 `rgba(0,0,0,.08)`
   换成深墨的低透明度，暗色分支原样保留。
2. `styles/components/post-hero.css` 的文章开头信息面板（AI 摘要 / 封面图那张卡），
   `--intro-surface-bg` 从无色相的 `oklch(0.965 0 0)` 改为 `oklch(0.958 0.014 78)`。

### 调参入口

想改光晕强弱 / 颜色，只改 `tokens/colors.css` 里这三个变量，别去动 CSS 里的渐变本身：

```
--ambient-warm   暖杏（左上）
--ambient-mint   薄荷（右上）
--ambient-violet 藕紫（右下）
```

每个都是「色相 + 色度 + 明度 / 透明度」四件套，把透明度从 `0.5` 调到 `0.25`
就淡一半，调到 `0.85` 会明显偏色。底色想更暖就调 `--page-bg` 的 chroma
（现在 `0.011`），但别超过 `0.02`。

### 影响面

- 只改亮色主题，暗色 token 一个没碰。
- 首页零改动（截图比对过，全屏主视觉原样）。
- 无需构建即可验证：`pnpm dev` 打开 `/posts/`、`/about/`、`/archive/` 三个页面即可看全。
