## 导航页（/projects/）改版

从「页头大标题 + 横向胶囊标签 + 卡片网格」改成参考站（kulayu.com）那种两栏结构：

```
┌──────────────┬──────────────────────────────────────┐
│ 全部      50 │  🔍 搜索网站…                         │
│ 我的网站   9 │  ▤ 我的网站 9 ────────────────────   │
│ 常用网站   1 │  ┌────────┐┌────────┐┌────────┐┌────────┐
│ 工具网站   8 │  │icon 名称││icon 名称││icon 名称││icon 名称│
│ …            │  │    描述││    描述││    描述││    描述│
└──────────────┴──────────────────────────────────────┘
     13rem                     自适应（4 列卡片）
```

- **左栏**：粘住的分类列表（图标 + 名称 + 条数），当前项浅底 + 左侧 2px 短竖条；首项「全部」。点分类只显示那一段，并把分类写进 URL（`#nav-分类名`），刷新/分享能回到同一分类。
- **内容区**：占满右侧（参考站最右边那列推广位/最新列表不做）；分区标题行 = `[分类图标] 分类名 · 条数 ｜ 子标签… “一句标语”`，中间那条横线按要求去掉了，标语靠右（`margin-left: auto`）。
- **标语**：17 个分类全部写好（`CATEGORY_META` 的 `tagline`），显示时用 **CSS 加的双引号**（文案里不写引号）—— 主题色的衬线引号、比正文略大一号，比纯文本引号更耐看；字号 0.8125rem，窄屏（≤1023px）整块隐藏，把空间让给子标签。
- **子标签（按标签分）**：导航条目新增可选字段 `tags`（zod schema 与后台 `.pages.yml` 都已加「标签」项，可多选），同一分类里出现过的标签会变成标题行上的那一排子标签：点谁按谁筛这个分类的卡片，默认「全部」；当前标签背后是参考站同款那道斜切渐变（`skewX(-15deg)` + 主题色 22% 渐变）。**一个分类里一条标签都没填时，这一排不渲染**（不影响现有展示）。标语取 `CATEGORY_META` 的 `tagline`，留空即不显示。本次已给**全部 11 个分类、50 条链接都打上标签**（每个分类 1–6 个，按条目类型分：我的网站＝站点/存储/机器人/工具/评论、工具网站＝图片/网络/图标/字体/地图/视频、设计资源＝组件/字体/壁纸/美化/前端/素材、开发者工具＝IDE/数据库/文档/AI/教程/评论、学习网站＝打字/编程/面试、AI＝对话/编程/API ……），所以现在每个分类标题行都能看到那排子标签。
- **悬浮看完整信息**：卡片上的描述只占一行（超出省略），鼠标悬浮（或键盘 Tab 聚焦）时在卡片下方弹出深色小气泡 —— **完整不截断的描述** + 小字域名，带一个指向卡片中心的小三角。浮层是一个共用的元素、由 JS 定位：贴住视口左右边界（最右列的卡片也不会被裁），下方放不下就翻到卡片上方；滚动/移开/失焦即收起。触屏没有悬浮 → 卡片描述在 `@media (hover: none)` 下改成两行。
- **整页宽度**：站长要求「不要占满整个页面，占 4/5」—— ≥1280px 时内容区取 `80vw`，768–1279px 用满可用宽度（`no-sidebar-pages.css` 里逐页一条规则）。
- **卡片**：参考站的两行式（图标 + 标题 / 描述），去掉原来的域名脚注与右上角跳转图标；网格 4 列（窄屏 3/2/1），悬浮时卡片上移 1px + 浅底。
- **图标「蹦一蹦」**：悬浮卡片时图标播一次 1.2s 的关键帧 —— 下压（`translateY(8px) scaleX(1.2) scaleY(0.8)` 压扁）→ 起跳带 5° 旋转 → 落地 → 小回弹，关键帧原样复刻参考站；动画挂在图标外层容器上，图片图标和字体图标都能跳，`prefers-reduced-motion` 下不播。
- **搜索（输入即筛）**：圆角输入框 + 左放大镜 + 聚焦变深边框，匹配**名称 / 描述 / 域名**（150ms 防抖，纯前端，不发请求）；搜索结果与标签是**与**关系（先按标签、再按关键词）；有结果时右侧显示「找到 N 个」，无结果显示空态 + 清空按钮，Esc 与 × 都能清空；**一开始输入就自动切到「全部」**，搜的是整站收藏而不是当前分类。
- **窄屏（≤1023px）**：左栏收成顶部横向可滑的胶囊条（当前项反色），搜索条在下面，卡片单列（≤640px）。
- 分类顺序：补齐了 `AI` / `开发者工具` / `开发者服务平台` 三个原本没登记的（会掉到列表尾部），现在按「我的网站 → 常用网站 → 工具网站 → 开发者工具 → 开发者服务平台 → AI → 学习网站 → 文档 → 设计资源 → 实用项目 → API」排。

### 两个坑（写进 CLAUDE.md 了）

- **左栏 sticky 又被 `overflow: hidden` 干掉**：祖先 `#main-content-wrapper` 与页面外层卡片都是 `overflow: hidden`，它们会成为「滚动容器」而自身不滚，sticky 于是失效。本页把两处换成 `overflow: clip`（裁剪一样、不产生滚动容器）。
- **图标空白**：本页图标统一走 `is:inline`（内联路径），避免 astro-icon sprite 丢符号导致整块空白（动态页踩过）。

> 验证：`pnpm check` 0 错误；`pnpm build` 通过；浏览器实测 1440 / 390 两档 —— 左栏 208px 粘住（滚到 2200px 时 top 仍是 88）、内容区 1152px（= 1440 的 80%）、卡片 4 列各 204px；点「工具网站」只剩该段且 `#nav-工具网站` 生效、刷新后仍在；搜「小米」1 条、「deepseek」1 条、「zzzzq」0 条 + 空态、清空还原 50 条；给三条目临时打上「常用/在线」标签后：标题行渲染出 `工具网站 8 ｜ 全部 常用 在线`（当前标签带斜切渐变）、点「常用」剩 2 条、点「在线」剩 2 条、叠加搜索后按与关系收窄，验证完标签已还原；真鼠标悬浮时 `getAnimations()` 报 `nav-icon-jumps` running（1.2s、1 次）；首页/其它页面布局与 overflow 未受影响。

> 插件侧：AstrBot BlogCreator 的 `DaohangWriter` 本来就把 `tags` 列为可选字段（`optional` 里有、`build_md` 会写成列表），加了这个可选字段后**无需改插件**。不过它的 `required` 仍是 `name/url/category` 且照样写 `category:` —— 那是 9/21「文件夹即分类」之前的老约定，跟现在的 schema 已经脱节（本站 zod 会忽略未知字段，所以不报错），要不要一起修另行确认。
