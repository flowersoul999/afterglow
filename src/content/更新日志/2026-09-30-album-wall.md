## 相册页（/album/）重塑

- **所有相册的照片拆开铺成一面墙**：238 张（11 个相册，全部走图床 imgbedFolder，客户端并行拉取），
  CSS columns 瀑布流（桌面 5 列 / ≤1280 4 列 / ≤1023 3 列 / ≤768 2 列）。
- **顶部筛选条**：第 1 行搜索 + 计数（共 N 张 / 已筛 N 张）+ 清空；第 2 行相册名（选中 = 主题色 + 2px 下划线，
  不是胶囊）。**按要求不吸顶**，跟着页面上滚。标签那一行按要求删掉了，只留相册名。

- **点照片开灯箱**：自研、跨整面墙切换、键盘左右键与 Esc、触摸滑动。
- **删掉单相册页** /album/&lt;id&gt;/ 与其专用组件 BounceCards；全仓 grep 确认站内没有指向它们的链接。
- 左右小组件全去掉（album-list 加进 NO_SIDEBAR_PAGE_TYPES），整页宽度 4/5。

## 坑：Astro 作用域样式套不到 JS 动态创建的元素

照片是脚本建的，而页面 &lt;style&gt; 默认是作用域样式（选择器带 data-astro-cid），JS 建的元素没有那个属性，
于是 .alb-photo 的规则**完全不生效** —— 表现是「点了相册，计数变了但下面的图没变」（站长报的正是这个）。
本页样式因此必须写成 &lt;style is:global&gt;（规则都带 alb- 前缀，不会外溢）。
另外：在 dev 里改完 .astro 的样式看不到效果，是 Vite 的样式模块缓存没失效，把文件重写一遍即可；
**判断真假要看 pnpm build 的产物**（构建不受 dev 缓存影响）。

&gt; 验证：pnpm check 0 错误；pnpm build 通过；产物 CSS 里确认相册样式未被作用域化、.alb-photo.is-hide 规则存在；
&gt; 浏览器实测 1440：238 张照片渲染、顶部条 position: static、图片上无文字、点相册筛选与再点取消。
