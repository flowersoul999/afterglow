## 各页面标题统一为 PageTitle

站长要求「其他页面的左上角也换成导航页那种样式（含动画）」。做法是**在原来的位置替换**原来的标题，而不是在内容区上方另加一个。

- **有原标题的页面 → 原地替换**（原来的「图标 + 大标题 + 描述」整块换成 `<PageTitle>`）：`归档`、`分类标签`、`更新日志`、`应用展示`、`赞助支持`、`去过的地方`、`相册`、`友链`。
  - 归档页的年份下拉是功能，保留并移到标题下方；
  - 友链页的「添加友链」按钮保留，改到右对齐一行。
- **本来就没有可见标题的页面 → 在内容顶部新增**：`动态`、`账单`、`日程`、`朋友圈`、`留言板`。
- 每页的 `eyebrow`（英文小字）与描述按页面语义撰写，例如 `Archive` / 「按时间翻阅写过的所有文章」、`Categories` / 「按分类与标签浏览文章」。
- 动画即 PageTitle 自带的 SVG 签写入场（描边→实心 + 淡入），`prefers-reduced-motion` 下自动降级。

> 验证：`pnpm check` 0 错误；浏览器实测 5 个页面（归档 / 分类标签 / 更新日志 / 友链 / 动态）每页**只有一个** `.page-title`、上方不再有重复标题；归档页截图确认标题块下方紧接年份下拉与热力图。
