## 首页换成了参考站的白色波浪网格演出

首屏不再是暗黑的取景框 + 对话框，改成参考站那套「拼图缝线网格 + 飘浮照片碎片」：
大标题走 canvas 虚线描边与跟手选择框，六块碎片按固定布局停住，随滚动拼成整图再淡出；
右下角的 B 站标识用 gooey 滤镜做熔化流动字。后续数据层、角色气泡、影像叙事层
一并接入，移动端走独立的 `HomeMobile`。

原版首页组件（`HomeTicker` / `HomeDisplayLayer` 等）仍保留在仓库里，只是首页路由不再渲染，
随时可以切回。

## 顶部导航加了灵动岛音乐面

三段式胶囊中段新增 3D 翻转的音乐面：唱片封面 + 「正在播放 {歌名}」跑马灯 + 四根波形柱
（兼播放/暂停按钮）。右上角音符按钮切换页面面/音乐面，收到 `fm:track` 时自动翻到音乐面。
胶囊改成了液态玻璃质感与弹簧感过渡，原有激活态、下拉面板、工具面板逻辑全部保留。

## 左下角歌词接上 Meting 歌单

播放器整套换成带逐字揭示的版本：音源切到参考站同款网易云歌单（含《雨爱》），
歌词由 Meting API 随曲目返回，`timeupdate` + rAF 双时钟驱动逐字点亮，支持原文/译文/双显三种模式。

## 适配说明

- 文案身份保留本站的 jojo 与职业标签，视觉参数沿用参考站的动画节奏
- i18n 新增 29 个键；`HomeConfig` 扩展 `hero.mosaic/photo/sticker/contact` 与 `homeBlinds`
- 所有新增交互监听器用 `AbortController` 清理，跨导航单例走 window guard
