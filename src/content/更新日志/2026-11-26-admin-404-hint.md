## 改了什么

「我的状态」面板一直提示「内容接口不存在，请在 Cloudflare 重新部署最新版 Worker（需包含 /api/github/tree），并检查 /api/github/\* 路由」，但真正 404 的是 `/api/private/tree` —— 两条通道在 Cloudflare 上是**两条独立的 Route**，提示只提了其中一条，于是照着修怎么都不通。

- `EditorApiError` 多带一个 `endpoint` 字段（出错的具体接口路径），私有通道的四个请求都把路径填进去
- 404 文案按通道分开：走 `/api/private/*` 就直说缺 `jojocode.cn/api/private/*` 这条 Route；走 `/api/github/*` 就提示三条 Route 是否齐全
- 其余状态码文案不变（401 / 403 / 409 / 422）

## 关键文件

- `src/utils/editor/github-client.ts` —— `EditorApiError` 新增可选的 `endpoint`（默认空串，老调用点不用改）
- `src/utils/editor/private-client.ts` —— list / read / write / blob / delete 五处抛错带上路径
- `src/utils/editor/editor-store.ts` —— `describeError` 的 404 分支按通道分文案

## 想改的话

后台再报 404 时，先看提示里写的接口路径：`/api/private/*` 就去补私有通道那条 Route 或重新部署 Worker，`/api/github/*` 才轮到内容通道。完整部署步骤见 CLAUDE.md「私有通道」一节的「部署（三步）」。
