## 资料面板：悬浮触发 + 两栏布局

按站长要求把导航栏资料面板重做成参考站的形态：

- **触发方式改成悬浮**：鼠标移到站点名上即出现，移开（或移到面板外）约 140ms 后收起；站点名与面板之间的缝隙留了宽限期，避免鼠标穿过时闪断。触屏与键盘仍可用（点击、聚焦也能打开；点面板外或 Esc 收起）。
- **站点名不再变黑**：v1.46.0 那版「面板展开时站点名反色成黑底白字」按要求撤掉了，悬浮与展开都保持原样（浅灰胶囊 + 深色字），连 hover 的透明度变化也去掉了。
- **两栏布局**（逐值照参考站）：卡片 `flex` + gap 1.25rem + padding 1rem 1.25rem、`min-width: 33.5rem`、`max-width: min(38rem, calc(100vw - 2rem))`；左栏固定 18.5rem，右栏自适应。
  - 左栏：头像 + 昵称 + 职位 → 社交按钮 → **文章热力图**（12 个月各一列、每列 4 格 = 月内第 1–4 周段，格色按该段发文量分三级）。
  - 右栏：距周末 / 距月底 / 距年底三个倒计时 → **事件进度条**（国庆节 10/1、建站日取 `siteConfig.siteStartDate`，显示「下一次还有几天」与「上一次 → 下一次」的进度）。
- **数据来源**：热力图在**构建期**用 `getCollection("posts")` 统计当年发文量（不需要接口；跨年后重新构建会换到新年份）；倒计时与事件进度由客户端按当天实时计算，事件日期以 JSON 传给脚本。
- 新增 i18n 键 `profileEventNational` / `profileEventSite` / `profileMonthWeek`，5 个语言文件已同步。
- 顺带删掉了透明遮罩层 —— 悬浮交互下它反而会拦住「站点名 → 面板」的鼠标路径，还会让面板自己关掉。
- **仍未做的**：参考站的「点热力图格子看当月文章列表」与「其他站点」列表（前者要额外的右栏面板切换与文章标题数据，后者缺 `navBarConfig` 配置项）。

> 验证：`pnpm check` 0 错误；浏览器实测（1725×965，悬浮站点名）面板宽 536px（33.5rem）、左栏 296px（18.5rem）、`display: flex`；站点名悬浮前后背景均为透明、文字均为深色；热力图渲染 48 格、其中 25 格有热度；倒计时 3天/1天/93天；事件「国庆节 10月1日 · 2天 · 99%」「建站日 9月1日 · 337天 · 8%」（与 9 月 29 日吻合）。
