## 开发命令

| 命令               | 用途       | 说明                                  |
| ---------------- | -------- | ----------------------------------- |
| pnpm dev         | 启动开发服务器  | 热更新，改代码浏览器自动刷新                      |
| pnpm build       | 生产构建     | 生成 `dist/`，2-3 分钟                   |
| pnpm preview     | 预览构建产物   | 先 build 再 preview                   |
| pnpm astro check | 类型检查     | 检查 .astro文件的 TS 类型                  |
| pnpm type-check  | 完整 TS 检查 | tsc --noEmit --isolatedDeclarations |
| pnpm format      | 格式化代码    | Biome 格式化 ./src                     |
| pnpm lint        | 代码检查     | Biome 检查并自动修复                       |

## PowerShell 注意

PowerShell 不支持 `&&`，用 `;` 代替：

```powershell

pnpm build; pnpm preview

```

删除文件夹：

```powershell

Remove-Item -Recurse -Force node_modules\.vite

```

## 日常开发流程

```bash

pnpm dev          # 启动开发服务器，改代码自动刷新

pnpm astro check  # 改完验证类型

pnpm build        # 构建验证

```

## 性能测试

```bash

pnpm build; pnpm preview

```

然后用 Chrome Lighthouse 测 `http://localhost:4321/`。不要用 `pnpm dev` 跑 Lighthouse，开发服务器有 HMR 和未压缩依赖，结果不准确。

## 清理缓存

```powershell

Remove-Item -Recurse -Force node_modules\.vite

pnpm dev

```
